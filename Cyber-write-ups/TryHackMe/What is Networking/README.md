## Key Concepts

### What is a Network?

A network is a collection of devices connected together to share information and resources.

Examples include:

- Home Wi-Fi
- School network
- Corporate network
- The Internet

### The Internet 
 It is one giant network that consists of many, many small networks within itself.

### IP Address

- An IP address uniquely identifies a device on a network. It is a set of numbers that are divided into four octets.

- IP Addresses follow a set of standards known as protocols. 

Depending on where they are will determine what type of IP address they have: a public or private IP address.

- A public address is used to identify the device on the Internet, whereas a private address is used to identify a device amongst other devices. 

Example:   192.168.1.20

IPv4 consists of 32 bits.

IPv6 consists of 128 bits.

### MAC Address

MAC (Media Access Control ) address is a twelve-character hexadecimal number (a base sixteen numbering system used in computing to represent numbers) split into two's and separated by a colon.

This network interface is assigned a unique address at the factory it was built at.

An interesting thing with MAC addresses is that they can be faked or "spoofed" in a process known as spoofing. 

### Ping

Ping uses ICMP (Internet Control Message Protocol) packets to determine the performance of a connection between devices, for example, if the connection exists or is reliable.


## Commands Practiced

ping

Purpose: tests connectivity.

Example:   ping google.com

Spoofing

purpose: to break poorly implemented security designs that assume that devices talking on a network are trustworthy.


## Key Takeaways

- Every device requires an IP address.

- Networks enable communication.

- Devices have two means of identification, with one being permeable. These are: An IP Address and A Media Access Control (MAC) Address.
